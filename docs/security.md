# 连接与安全

[返回 README](../README.md) · [English](security.en.md)

## 连接方式

中继在运行 Agent 的电脑上通过 CDP 连接桌面应用；手机经过 HTTPS 公网隧道或局域网连接中继。固定网页入口可发现变化后的中继地址，使用已有凭据重新认证。GitHub Pages 入口与本机中继是不同组件；保留 `~/.agent-remote/`，并使用原操作系统用户启动中继。

## 配对与设备入口

- 用一次性链接、二维码或手动配对码授权。配对码有时效，只授权新入口；启用两步验证后仍需 Authenticator 验证码。
- 同浏览器内的刷新或其他页面可复用已保存凭据。其他浏览器并不会因为来自同一台手机就自动获得权限。
- 「已配对设备 → 添加入口」可邀请新浏览器，由已有可信入口核对验证码并批准。新入口取得独立凭据。
- 列表按“设备 → 入口”组织，自动归组依赖明确归属信息，不凭同名 iPhone、IP 或浏览器指纹推断物理设备。分组不共享授权；各入口可独立撤销。
- 移除入口会使其授权失效并断开相关长连接，不会结束已经在电脑执行的 Agent 任务或终端进程。

## 保护电脑和手机

只授权可信设备，保管配对链接，不公开带令牌的地址、二维码、配置和日志。CDP 调试端口应仅供本机访问，不直接暴露到公网；远程入口经过中继认证。使用 HTTPS，按需要开启 `npm run 2fa`，手机丢失时及时撤销入口。

```bash
npm run devices
npm run devices -- remove <id>
```

`npm run reset` 会清除全部配对、两步验证和相关配置，不是日常重连操作。它不会替你终止已经运行的桌面任务或隧道进程。

这套工具可操作真实终端、项目和当前操作系统用户可访问的文件，不提供独立系统沙箱。隧道的 HTTPS 传输也不等于已实现端到端加密；不要把“自托管”解释为无需信任电脑、隧道服务或前端入口。Agent 本身的账号、订阅和权限仍由对应应用管理。
