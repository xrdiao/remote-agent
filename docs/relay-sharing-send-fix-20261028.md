# Codex 发送与共享中继实施记录

日期：2026-10-28。用户授权范围为发送、接收确认、共享原生窗口读取、已配对电脑后台连接，以及对应 Agent／项目／会话切换。本轮保留原有本地修改，不提交或推送 master／debug，不测试修改 Fusion，不执行 Devin 专项测试。

## 实现

- Codex 提交优先点击原生 Send／Queue／Steer 的对应按钮一次。没有对应按钮但原生输入组件可提交时，调用同一原生提交动作；排队与立即追加显式传入 Queue／Steer，不临时修改默认设置，不先停止任务。提交不等待原生异步回调全部结束。
- 接收确认归到中继的窗口数据源，以原生消息／队列 ID 确认。移除普通 Codex 发送的独立等待与手机端重复认领；未确认仍为待确认，不冒充已发送，不自动重发。不同请求、会话及同文本消息分别关联；切换后迟到回执仍处理原请求，不清空后来编辑的草稿。
- 新增 `server/native-windows.mjs`：每个原生 CDP 端点共用物理连接、监听、最新有界快照和已完成正文缓存，手机入口只消费数据并保留各自选择及请求。取消一个读取消费者不取消其他消费者；同一窗口的写操作依序执行。来源随真实窗口关闭释放。
- 已打开的窗口通过原生数据变动通知更新；有消费者、待确认发送或原生活动时及时读取，空闲来源低频读取。预读不执行 `Page.reload`、切换会话、打开菜单或抢焦点。通知观察复用数据源，既有事件、去重、观看状态及投递逻辑保留。
- 已配对同源电脑各自维持认证连接，当前电脑优先，其他电脑异步连接。切走只标记未观看，不关闭健康连接；返回复用连接。后台消息只更新所属电脑数据，旧发送回执按原请求完成，不能覆盖当前界面。跨来源授权边界保留。
- 项目身份已匹配到真实窗口时直接绑定；同项目换会话复用窗口，不刷新原生页面。缓存预览仍须确认实际目标与首屏，不能冒充实时就绪。
- 配对浏览器检查发现新项目首屏还缺原生元数据就绪确认，且绑定早期的会话身份可能被沿用。已在原有同一等待预算内确认元数据就绪，发布首屏前读取实际身份，并只在实际目标变化时失效相应来源；没有新增固定延时或另一轮超时。

主要入口：`server/native-windows.mjs`、`server/session.mjs`、`server/agent/chat.mjs`、`server/agent/projects.mjs`、`server/agent/updates.mjs`、`server/apps/codex.mjs`、`server/apps/cursor.mjs`、`server/page/chat-extract.js`、`server/ws.mjs`、`server/index.mjs`、`lib/notify.mjs`、`app/js/net.js`、`app/js/notify.js`、`app/js/composer.js`。功能基准同步至 01、03、05、08。
