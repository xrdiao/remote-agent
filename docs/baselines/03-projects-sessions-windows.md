# 03 项目、会话与窗口

[功能基准索引](README.md) · 首次建档：2026-10-26 · 核对起点：`24e4cd7` / `v250`

## 功能与范围

按电脑和 Agent 浏览项目及会话，打开或创建项目／会话，筛选常用，设置星标，执行原生支持的重命名、删除／归档及批量管理，并管理可选的闲置项目窗口回收。

## 入口与正常流程

所有“项目与会话”入口使用同一份分组、筛选与会话动作语义，包括主输入框上方入口。列表保留“刷新”“选择文件夹／新建项目”“在当前项目新建会话”等操作。展开项目后应露出其会话内容；关闭再打开时保留用户操作合理位置，不能因旧位置看不到刚展开的会话。

电脑列表先选择软件并绑定所属目标，再进入与对话页相同的项目／会话列表。电脑入口选择目录从默认目录及最近项目开始；对话入口从当前原生项目开始，多根项目先选择。浏览文件夹与输入路径入口位于最近项目之前，目录选择复用电脑文件浏览器的路径栏、Tab／补全按钮和上级／根目录导航，只列文件夹。打开项目、新建项目／会话和原生信任确认继续使用原有动作；选择目录本身不提交原生打开动作。

同一 Agent、同一实际项目内切换会话，在当前窗口完成，不因原会话正在生成或列表记录了其他所属窗口而切换／新开窗口。只有实际切换项目才进入窗口选择流程，优先按项目身份复用可用窗口，需要时再打开新窗口。切会话必须核对目标实际生效；项目身份按实际路径与远程主机判断，不按显示名称判断。原会话的工作目录、任务和其他窗口不因切换而擅自改变。登录、工作区信任或原生启动未完成时按 08 展示真实状态。

RA 终端由电脑中继持有，按电脑和独立终端 ID 区分，不依附原生窗口或会话。对话入口新建使用当前会话的真实项目目录；Codex 使用原生会话目录／host，Cursor／Devin 使用其现有项目来源，不能因编辑器在 B 项目就给 A 会话创建 B 目录的终端。创建操作保留发起时的电脑和项目；切会话不改变已有终端目录，也不打开、聚焦或切换 IDE 项目。电脑入口默认主目录，明确选择目录时复用文件夹选择器。本地 PTY 不将远程 SSH／容器路径当作本机目录。终端操作和恢复见 [06](06-desktop-tools-media.md)。

## 项目与会话身份

- 按电脑、Agent、项目实际路径／远程主机、窗口和会话 ID 区分；同名项目、同名会话不合并成同一个目标。
- 展开、刷新、跨窗口和休眠项目恢复都使用明确的会话来源与项目归属，不把当前前台窗口当作唯一来源。来源窗口用于核对归属；同项目会话切换仍在当前窗口执行，不把来源窗口直接当作必须切换的目标。
- 项目分组使用实际路径与主机区分，同名不同路径的项目显示可区分的名称；每个实际项目只保留一个列表内的新建会话入口。
- 会话归属从目标窗口的原生元数据读取，不依赖切换前预读全部窗口列表；已关闭窗口的会话仍按已有明确归属恢复。
- 普通重连的目标由电脑端按电脑 ID＋独立配对入口 ID 保存，各 Agent 保留各自成功目标，实际成功读取并持久保存后更新；失败选择、缓存预览和迟到结果不覆盖记录。新电脑及加载页冷启动保留原生列表／空白页，不为恢复目标自动打开最近历史或新建会话。
- 切换后旧列表、旧标题和旧读取不能改变新目标；首屏内容和默认位置按 [02](02-chat-display-history.md) 核对。
- 标题、常用和星标不改变原生会话身份，也不重新创建会话。

概览、项目和收藏卡片按电脑、Agent、真实目录／host 与原生会话区分。同一项目的多个普通窗口共用项目分组，同一会话保留一张卡片，并携带正确操作窗口；项目名称来自真实目录。明确登记的 Fusion 子 Agent 专用窗口及其原生 Binding 会话只在 Fusion 栏目展示。Fusion 主 Agent 可使用普通原生会话，继续显示在普通项目与收藏中；其窗口和会话不属于子 Agent 的自动归档、回收范围。

收藏会话卡片和项目卡片的普通状态均按“已完成、进行中、空闲”排列，同状态按最近活动时间排列；待确认、停止／错误与状态未知分别展示。项目的徽标和排序共用同一聚合状态，仍有运行或状态未知会话的项目不能显示为全部完成。完成标记必须对应同一原生轮次的明确结束，切走、返回主页或暂缺读取不构成完成。

Codex 的“待确认”与聊天页共用当前原生问题／执行审批请求。请求卡片出现时标记，请求消失后清除，正文来自真实问题；没有消息列表时也保留待答请求。文件改动的 Accept／Run／Continue 等普通按钮不单独构成待确认。当前 userInput 的标识包含所属会话、轮次、原生请求和题目 ID，数字 0 也是有效请求 ID；编辑答案不产生新问题，同文不同请求分别识别。答案、选项和多题切换复用原生状态及回答回调，不把其他会话的卡片归入当前会话；同一原生卡片只展示一次。正常结束后继续按既有完成／空闲规则展示，不通过待确认状态推断任务结果。

已建立本入口基线后，原生轮次 ID 改变且原生开始时间明确晚于上一已确认轮次时，其明确完成结果也应生成完成标记，不要求手机曾读取该轮的运行快照。首次载入的历史完成不补提醒；不同轮次缺少可比较的原生时间时不猜测先后。未知读取不替换已确认的轮次基线，迟到的较旧轮次不清除或重新点亮最新轮次标记；打开后刷新同一完成轮次仍保持已查看。

会话卡片的“已停止”和“已完成”标记都在点击“打开对话”时清除，仅展开卡片不清除。“已停止”的已查看记录保存在本入口，按电脑、项目、会话及原生轮次区分；同一轮次刷新或返回主页仍保持空闲，新轮次再次停止重新提示。项目汇总随会话卡片更新；原生停止结果保留，执行失败不按已停止清除。

已完成会话的长按菜单提供“已读”，与打开对话共用本入口的完成标记清除逻辑；操作后卡片、项目汇总和排序同步更新，不打开会话或修改原生轮次结果。同一完成轮次刷新后仍保持空闲，新的明确完成轮次可以再次提示。其他电脑、项目、会话的标记不变；待确认、进行中、错误和已停止不提供这个完成标记动作。

Codex 卡片打开同一就绪窗口内的会话时，复用项目／会话列表的切换功能；包括上次已就绪的同一会话，也要核对真实原生目标和首屏后再进入，手机保存的就绪标记不能证明桌面在后台期间没有改变。跨电脑时先接管目标电脑已就绪的连接，再打开指定会话或项目，不因目标会话与预加载会话不同而重新初始化电脑入口；快速选择以最后一次目标为准，草稿保留各自归属。其他已有项目窗口继续按实际目录／host 复用并绑定，没有窗口时才启动项目窗口。Codex 项目先立即读取原生就绪状态，确实未就绪才沿既有预算等待；登录、信任及原生启动进度按实际状态显示。绑定尚未完成时，恢复会话不提前重复读取首屏，由最终绑定流程统一读取；普通已就绪会话切换仍直接读取目标首屏。

展开卡片已发起后台绑定、且同一电脑／应用窗口／会话仍在导航时，点击“打开对话”等待该绑定及首屏，不重复发起导航；连续点击只让最后一次打开意图进入。展开 A 后打开 B，仍按 B 的目标请求并等待确认，A 的迟到结果不能带回 A。关闭或改选卡片后放弃原等待；读取失败后再次明确点击沿原路径重新请求。已经就绪或无需发起导航的绑定不适用在途复用，仍保留上述原生目标确认。

会话卡片的“打开对话”明确进入聊天模式。从终端返回主页后打开另一会话时，先切回聊天且不请求恢复旧会话，再等待所选目标的真实首屏；身份确认或缓存预览不提前进入，旧终端及其未发草稿继续保留。Fusion 主对话同样沿此入口，以原生主会话的窗口／会话及工作台关联确认，不把 Fusion 入口标识当作最终原生身份。未启用主 Agent 时仍只打开配置；浏览 Fusion 状态及电脑的独立终端入口不改变上述语义。

折叠卡片、展开卡片及已启用的 Fusion 主对话，均按明确的电脑／应用窗口／会话目标打开。相同目标的实际导航尚未结束时，连续点击复用同一次原生请求；已完成、失败或连接已更换后，明确点击会重新确认目标。后台准备不覆盖前台进入意图；展开 A 后打开 B、快速 A→B、关闭／改选时，旧响应不能再进入 A。

打开期间在所属卡片／工作台显示等待首屏；失败原因与“重试打开”同样留在主页可见位置。只有目标的实际绑定和新鲜首屏就绪后才进入，缓存不冒充确认。保留电脑范围、返回位置、聊天／终端草稿和既有终端。

## 筛选、星标与名称

| 功能 | 行为约定 |
|---|---|
| 筛选 | 只筛选会话，提供小型“全部／常用”切换；没有独立项目筛选或“不常用”选项 |
| 项目分组 | 保持项目与会话层级；筛选不能把不匹配会话放回结果或破坏创建入口 |
| 自动常用 | 根据最近 7 天的实际会话消息使用时间判断；打开列表、刷新、读取历史不冒充发送使用时间 |
| 手动星标 | 星标会话可列为常用；取消星标后仍可能因为最近 7 天使用而属于常用，两者不是同一事实 |
| 多手机共享 | 同一电脑的共享会话元数据由电脑端保存并同步；不能只把名称／星标保存在单台手机 |
| 列表顺序 | 筛选改变可见集合，不擅自替换已有排序规则；名称变化不改变会话 ID |
| 当前标识 | 保留对号；不额外重复显示“当前”徽标，运行中状态另有意义 |
| 会话动作 | 右侧星标及“…”入口独立于打开会话；菜单按原生真实能力展示 |
| 重命名 | 确认成功后列表、切换前后及刷新显示一致；读取旧缓存不能作为更新名称的事实 |

## 单条和批量管理

Cursor、Devin、Codex 的原生动作可能不同，不能为界面整齐把“不支持”伪装成成功。删除、归档、重命名均需对应到实际会话，原生结果反馈后再更新列表。

Fusion 主页与收藏中的工作台卡片复用普通会话的长按手势及菜单样式；移动、滚动或取消结束长按，菜单出现后的释放不误触打开。菜单按电脑和工作台身份提供主对话、任务、设置、已读、收藏、改名、停止和删除；工作台名称与收藏由所属 relay 保存并向既有配对入口同步。工作台改名先按实际主Binding在后台更新当前原生主会话，原生确认后再保存工作台名称；原生规范化后的实际名称保持一致，失败或未知不报成功。子Agent及其他普通会话不随工作台改名，收藏分别归属。收藏中的工作台使用同一张 Fusion 卡片及同一打开路径，普通会话菜单、批量管理及排序规则保持原义。工作台删除的原生清理及回执要求见 [07](07-fusion.md)。

批量管理允许按当前结果选择、执行和取消剩余操作，逐条显示成功或失败。取消不撤销已经完成的删除／归档；断线后的未知结果先核对列表，不能自动重复执行。运行中的会话和 Fusion 占用遵守现有操作限制。

## 闲置窗口管理

自动关闭为可选功能，记录管理范围、空闲时长及始终保留偏好。判断包括正在查看、Agent 执行、未保存内容、原生对话框、终端／后台进程、自动化工作、上传及 Fusion 占用。关闭前重新确认目标和活动，至少保留该 Agent 的一个可用窗口；无法确认时保留。平台不支持的探测／关闭要明确，不声明所有系统已经支持。不能仅因手机切走或后台一段时间就关闭窗口。

## 回归场景

| 操作 | 观察结果 |
|---|---|
| 三 Agent 各展开项目、打开／新建会话、往返切换 | 正确目标与首屏，原任务和工作目录保持 |
| 同名不同目录项目、多个窗口及后台目标 | 不混淆，目标不是前台窗口也能恢复 |
| 切换全部／常用，设置／取消星标 | 可见集合正确；排序、层级与新建入口保持 |
| 两个已配对手机查看名称与星标 | 同步到同一电脑会话，不串电脑或 Agent |
| 菜单重命名／删除／归档，再刷新或重新进入 | 支持的动作实际生效，能力不支持有真实反馈 |
| 批量选择、部分失败、取消、断线再返回 | 已完成结果保留，未知不重做，可退出管理 |
| 测试窗口处于运行、终端工作、未保存、最后窗口状态 | 自动管理按约定保留，仅关闭明确可关闭的闲置目标 |

## 关联检查与维护

发送时间读 [01](01-conversation-input.md)，首屏读 [02](02-chat-display-history.md)，原生动作读 [04](04-native-controls.md)，Fusion 占用读 [07](07-fusion.md)，绑定及跨电脑读 [08](08-connection-pairing.md)。只在独立测试项目／窗口上验收关闭和删除。

本次建档未执行上述功能回归，也未关闭或删除真实会话／窗口。

列表的显示归属：主动打开列表时立即显示其加载／缓存内容；关闭或进入其他弹窗后，迟到的列表读取只更新缓存，不重新打开列表。重命名、删除／归档按当前操作明确返回列表；项目展开聚焦及列表自身滚动保留。

Codex 会话列表必须先按原生 workspace／host 保存真实项目身份，再生成展示列表；不能用列出该会话的窗口目录替代会话目录。恢复时当前原生元数据优先于过时的休眠记录，同项目切会话仍使用当前窗口。

Windows 本地 Devin/Codex 项目切换完整传递目录参数，目录中的中文、空格及符号不变成命令语法。Cursor、Devin、Codex 项目分组使用末级目录名，同名时补充区分信息，保留原始项目身份。Devin 打开会话使用对应会话的主入口，与行内操作按钮分开定位。

Windows Codex 复用已匹配项目窗口切换会话时，以原生 Agent 运行状态判断是否可切换，不把终端缺少命令检测器等同于 Agent 正在运行；切换不操作终端。Devin Agent 界面以原生侧栏选中会话为当前身份及目录，后台残留日志不能覆盖新选择；Editor 界面的标签归属保持独立。

Codex 恢复已知会话时等待原生导航入口可用，并核对目标会话实际生效。普通会话导航保留 35 秒预算；首次恢复使用 08 所述请求剩余预算，不在内部重新开始 35 秒。WebView 存在不等于会话可导航，最近列表尚未加载或未包含该项也不等于会话不存在；加载未就绪与目标未找到应分别反馈。

入口恢复使用保存的真实项目路径与主机定位窗口，再恢复其会话；窗口已关闭时沿既有项目打开流程恢复本地项目，不能向其他项目窗口注入旧会话。明确指定且已关闭的窗口没有项目身份时返回初始选择页。失败不删除原生项目／会话或其他入口记录。

导航以实际会话为目标、窗口为操作载体。同项目更新原窗口的会话；跨项目匹配实际项目后复用／打开窗口。一次导航的最终就绪回执应同时携带真实目标身份和首屏，绑定过程中的进度不冒充最终成功。当前标记按确认后的选择更新，不为普通切会话重复扫描所有窗口；创建、改名、删除／归档、窗口变化及显式刷新保留相应列表更新。已有窗口已经显示目标会话时，绑定该会话不检查与本次操作无关的终端；需要改变其会话时仍遵守原有占用规则。

Cursor 在切换确认中核对原生会话加载状态与正文挂载；会话 ID 先变化不代表正文已可读，原生确认的空会话可以正常进入。

已有项目窗口、会话目录和最新一页由中继按窗口共享读取。后台只读预热不改变原生当前会话、最后成功选择或实际使用时间；明确项目身份已匹配到窗口时直接绑定该窗口，不先绑定无关项目。普通切换复用窗口连接与已完成正文，实时运行态和原生动作仍按当前实际数据处理。

显式要求最新首屏时，窗口共享读取至少完成请求开始时已观察到的版本；旧版本正在读取时复用已有后续读取，不能把其旧结果作为本次最新结果。目标版本固定在请求开始时，生成继续变化不延长本次等待；其他普通读取和会话切换取消保持原有语义。Codex 卡片运行状态直接读取原生最后有效轮次的 ID、状态及时间，省去为每张卡片重新解析完整正文，完成／待确认定义保持。

Devin 可以有独立 Agents 窗口，也可以在同一个项目窗口中切换 Agents／IDE 布局；当前布局读取原生模式控件，不用不随布局变化的窗口静态配置替代。RA 默认进入 IDE，保留明确的目标会话与实际项目，先切换布局／绑定正确项目，再读取会话。独立 Agents 的当前目录来自所选原生会话；其底层编辑器配置不能作为 IDE 项目窗口候选。IDE 的完整会话目录、其他项目查询与导航查找共用原生有效会话元数据，包含尚未打开为标签的会话；不依赖侧栏是否可见或列表缓存中的旧来源窗口。列表、正文及操作统一使用原生 ACP 会话 ID；Webapp 包装 ID 与 Cloud 原始 ID 在 Devin 适配层规范化。界面切换保留会话身份，完成窗口绑定后再结束切换并发布首屏。

Devin 会话操作读取实际的原生动作；新版提供归档而没有删除时只提供归档。IDE 的 Past Conversations 若原本已打开，不反向点击关闭；只关闭本次操作打开的选择器。

Cursor 打开会话按原生目录确认有效 ID，再调用原生 openComposer；不要求该会话已经挂载在侧栏或正文。原生不存在、归档或未就绪分别反馈真实结果；旧来源窗口失效时沿既有实际项目恢复，不更换会话身份。

Devin 跨项目会话打开期间，焦点租约属于实际操作的目标窗口；不沿用旧窗口的焦点，不关闭本来已经打开的历史选择器。历史入口按原生挂载就绪，不把模式状态已改变等同于历史菜单已可用。
