# 07 Fusion：持续主 Agent 与后台子 Agent

[基准索引](README.md) · 2026-11-05 新契约，替代旧 run 与专用子窗口流程。实施、切换和验证边界见 [Super Agent 方案](../fusion-super-agent-20261105.md)。本文件描述应有行为，不表示真机验收已通过。

## 入口与主会话

底部“概览｜项目｜收藏｜Fusion”横竖屏一致，共用电脑范围；全部电脑不静默挑选执行电脑。点击导航仅读取状态，进入后返回 Fusion 并恢复电脑范围。切页、普通会话切换与手机断线保留草稿及后台 Runner。

工作台长期管理多个工作项。项目选择／新建／信任复用现有流程；主项目有窗口则复用，没有则按普通项目流程打开。当前单会话工具主控为 Codex；Cursor、Devin 的主控接入未经同等隔离验证，不宣称可用。

主 Agent 使用完整普通原生会话功能，模型及思考强度由用户选择。Fusion 在主对话旁提供设置及任务关系。工作台文字收件箱可交办新需求、补充具体工作／任务、回答问题；登记回执不等于原生接受。只读查看任务板不切换桌面会话。

## 打开、详情与证据读取

已启用的工作台点击后直接走普通会话的既有导航链路，按实际主绑定确认 Codex 窗口、原生 thread 和工作台身份，不先等待完整工作台数据。未启用的工作台只读取配置。异步配置、任务和审计回复只属于发起它的视图，切走后不能重新弹出或抢占后来选择。

工作台列表及主对话头部使用摘要；主绑定确认的 attached 携带必要关联，原生主聊天不附带整份工作台。配置、工作／任务列表、选中任务、输入问题分别按用途读取，不把全部事件、历史正文、大差异和每次 Attempt 重复的实时正文放入默认状态。

选中任务的正文与历史沿用 fusionContent 分页；实时交互只取选中任务最新执行的按钮、审批、问卷和状态。展开具体执行记录、评审或交付证据才读取完整数据，结果、基线、差异及证据不截断、不删除。Fusion 原生按钮使用自己的目标标记，操作只发送给所属执行绑定。

详细状态只订阅正在查看的视图，关闭或切换后释放，保留摘要；连接恢复时仅恢复仍在查看的视图。更新详情时保留输入、选择、焦点、光标、审计展开项及滚动位置。Runner、派工、成本、模型、停止／恢复与持久化格式保持原语义。

## 主控与持久任务

原生单会话 `ra_fusion` 工具是唯一管理入口；真实主 thread／turn／request ID 与 Runner decisionId 关联。请求 ID `0` 正常处理，重复命令不重复派工。子回复、历史、思考和文本 `fusion-control` 不执行。

Controller、WorkItem、Task、Worker、Assignment、Attempt、Binding、输入／事件／效果分别保存。一个主控管理多项工作；简单问题零子任务，复杂工作按依赖分批派工，无固定数量和轮数。项目 AGENTS.md 要求确认时展示具体范围和标准，确认后才派工；已授权范围内分工不逐个请示。

主控验收真实结果，补做新增 Attempt 并续接原子会话。交付逐项关联完成标准与证据；必需任务、未处理新输入和未知执行均须核对，主控实际轮次完成后才确认工作项交付。完成工作项不关闭主工作台。

## 后台执行与普通会话隔离

同软件 Worker 使用主窗口中的独立原生会话；跨软件复用该软件已打开的窗口，不创建子窗口。通过明确 app／host／目录／thread 的原生管理器读写和订阅，不借当前可见对话的 DOM 代替后台事实。普通项目、草稿、模型、权限、队列、会话和监听均保持原功能。

普通窗口由用户切到其他会话时，普通发送仍按原规则拒绝；Runner 不强行切回。后台任务只操作自己的绑定与实际原生轮次。主 Agent 按输入产出、文件、命令和共享资源判断依赖与冲突，用 `dependsOn` 或分批派工决定串并行；relay 不按软件、项目或读写类型强制互斥。同软件、同项目的独立写任务可并行，不同软件有依赖也必须顺序执行。截图验收后再修改依赖截图的 README；两个互不冲突的功能可以并行实现，后续集成和验证依赖对应任务验收。主控自己执行同样遵守其登记依赖。

同一工作台的主控决策保持顺序，同一任务未结束或原生结果未知时不能重复提交；未知执行只保留在其任务与 Attempt，不占用全软件或全项目。当前策略通过 `read_workspace` 告知历史主会话。记录执行前已有改动和本任务的负责范围，原有及其他并行任务的改动不算本次成果，不创建 worktree 或自动合并。

子 Agent 和原生会话持续保留，不自动归档、删除、隐藏或关闭。每次原生生成结束释放该次监听和连接，不影响同窗口其他任务；后续相同任务可重新调用原子会话。共享窗口继续使用原有普通空闲扫描与收藏关联规则，没有专用 Fusion 回收流程。

## 成本、停止与恢复

均衡默认，三档只表达取舍，不限制模型或强度。成本与候选保留原生来源、时间、Free／倍率／套餐原单位；未知金额不猜账单，账号整体变化不归为子任务精确费用。派工保存自做／委派总开销比较。只有用户显式设置并可用原生单位核对的预算形成边界。

停止由 relay 直接处理，范围可为任务、工作项或整个工作台；先取消未提交队列，只停止实际绑定的本次原生轮次。未确认保持 stopping。原生权限保持原义，后台无法安全处理的交互说明原因并等待，不自动批准或切换普通会话。

relay 恢复进入 recovering，核对已接受与已结束事实；仅确定未提交才发送，未知执行 blocked，不自动重发。失联、额度不足、错误和中断均不表示完成。

旧元数据备份并清理明确属于旧 Fusion 的字段，不迁移或保留旧引擎；其他 relay 状态、原生会话、收藏、项目映射和普通窗口保留。Devin 原生 Fusion 模型模式独立保留。

## 验收

受控状态机覆盖零／多任务、DAG、补做、三档、去重、事件合并、停止／恢复、预算，以及同软件／同项目独立写任务并行、跨软件依赖串行、多个未知轮次恢复与连接释放。真实原生核对各任务回执、执行时间是否重叠、后台并发、原会话隔离和重复调用；配对浏览器核对任务及原生内容归属、草稿和普通导航。用户手机按实际范围另行验收；缺少条件或未执行的项目保持待验，受控通过不等于真实并行验收通过。
