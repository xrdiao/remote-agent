# 06 文件、终端与媒体工具

[功能基准索引](README.md) · 首次建档：2026-10-26 · 核对起点：`24e4cd7` / `v250`

## 功能与范围

本类覆盖用户直接使用的电脑工具：Editor、文件预览和差异、图片／文档附件、图片编辑、双向文件传输、语音输入、终端及绘图／仿真画面。以下各功能独立保持自己的输入目标、权限和资源；同属一类不表示要合并实现。

## Editor 与文件预览

- 从项目文件、聊天引用或变更列表进入对应电脑和项目的文件。完整路径、相对路径和裸文件名要区分，同名不同目录不能静默替代。
- 文件 URI 保留完整主机、转义内容及行号传给所属电脑解析；Windows 本地盘根和 UNC 共享根保持原身份，Linux／SSH 路径保留各自语义，不根据手机操作系统转换电脑路径。
- 展示实际文件名、路径和内容；文本保留原内容，按可用主题／语言高亮，可换行、搜索、定位和查看差异。
- 电脑列表和对话页的 Editor 使用同一文件浏览、路径输入、Tab 补全、预览、编辑保存与返回目录流程。电脑入口从根目录／盘符开始；对话入口只读取原生当前项目元数据后从该项目开始，不先重复扫描一份项目文件列表。可继续浏览所属电脑用户可访问的本地目录，路径解析使用该电脑的操作系统规则。
- 文档与代码均通过共享 Editor 浏览、预览；不再保留独立“查看文档”的旧项目列表与目录扫描。当前项目元数据读取仍保留多根选择、错误回执及电脑／会话／请求归属。
- 保存有明确回执，失败／未知保留编辑内容；未保存离开有确认。切文件时旧读取或旧绘制不覆盖新文件；关闭预览返回同一浏览器、目录与滚动位置，不重新枚举目录。
- 文件保存完成以电脑写入结果为准；手机断线保留此次保存及编辑内容，重连恢复电脑结果，不因手机等待时间推断保存失败或自动重复保存。
- 保存正文不得擅自改变原文件权限；可执行文件仍可执行，原有限制权限保持。
- Git 差异、Agent 差异和最近提交标记保持真实来源及文件身份；没有可定位行时不捏造对应关系。
- 图片展示及缩放使用真实引用；PDF 通过页码／上一页／下一页阅读全部可读页面，支持页面内双指缩放、放大后拖动和适应页面；翻页重置缩放，切换或关闭结束过期任务。
- MP4 保留播放、拖动及分段 Range 读取；双指缩放与移动不抢占原生播放控制条。

## 图片、文档与引用

1. 手机选择图片或文档，上传到当前电脑并归属于当前会话；展示进度、完成、失败和取消。
2. 图片可批量编辑，提供裁剪、比例、旋转、画笔／形状／文字、移动、撤销／重做、缩放及逐图排除。保存前是本地编辑，取消不替换电脑原件。
   “取消编辑，上传原图”放弃本次改动并继续上传未提交的原文件；“取消上传”结束本次上传。编辑已有附件时“取消编辑”保留原附件，不发起替换。已加入上传的图片不重复提交。
3. 批量保存按实际已加入上传的结果推进；取消后续上传不假装撤销已经提交的图片，单张失败不永久锁住整个编辑器。
4. 发送后按对应用户消息展示图片缩略图；历史图片是否能读取受原文件／缓存存在性约束，不能放错消息。
5. “添加电脑端文件”与“手机上传文档”是不同入口；@ 引用遵守 Agent 原生索引及路径语义。
6. 切电脑、会话或断线时，旧上传结果不加入新目标；待发送附件与消息接收关系见 [01](01-conversation-input.md)。

## 双向文件传输

| 功能 | 行为约定 |
|---|---|
| 入口与归属 | 主页已连接电脑行右侧提供该电脑的传输入口，替换连接详情图标；断线时保留连接详情。原菜单入口使用当前电脑。浏览、下载、上传和文件操作均归属入口选定的电脑，不切换当前聊天电脑／Agent，电脑认证后不等待项目读取 |
| 返回 | 传输占据独立浏览器历史，按钮返回和浏览器返回回到打开前的会话或主页状态；接收目录选择的面板内返回仅取消选择 |
| 浏览 | 当前电脑操作系统用户可访问目录，不限于项目；传输多选和上传队列保持独立 |
| 选择 | 跨目录多选、全选本页、清空；列表过滤不应悄悄改变已经选中的目标 |
| 下载 | 单文件直接下载，多文件／文件夹流式 ZIP；保留子目录与空目录，不跟随文件夹内部符号链接 |
| 上传 | 先选接收目录，再统一添加文件／文件夹并上传；按相对路径创建子目录 |
| 重名 | 用户选择另存、跳过或覆盖；不能把一项的选择应用到另一完整目标路径 |
| 文件管理 | 支持新建文件／文件夹、跨目录复制／剪切／粘贴、保存 ZIP 及解压 ZIP；剪贴板按电脑及完整源路径保存，剪切只移除实际移动成功的来源 |
| 操作结果 | 文件写操作复用所属电脑的操作登记与结果恢复，同一 operationId 不重复执行；不归属于当前 Agent 或聊天会话 |
| 并发 | 当前最多两个上传并行，同一完整目标路径按顺序处理 |
| 进度／失败／取消 | 各项状态对应真实结果，失败可重试；取消清理属于本次任务的临时资源，不撤销已完成结果 |
| 上传记录 | 成功或按选择跳过的上传项释放 File 和列表行；失败项保留重试，未完成项保留，不维护成功传输记录 |
| 目录偏好 | 上传接收目录和下载浏览目录分别记忆；隐藏文件开关只控制列表展示 |
| 平台能力 | 浏览器未提供的目录／空目录信息不虚构；保存位置和下载取消由可用浏览器能力管理 |

## 语音输入

- 支持已安装的 Sherpa CPU、Qwen GPU 及可用的手机系统识别；选择按电脑记录在当前浏览器，不伪装引擎安装状态。
- 引擎列表用现有紫色对号标识当前选择，不再额外显示灰色对号；单选状态、可用性及切换时机保持原规则。
- 按住说话、松开收尾；首次授权、模型准备和真正录音是不同状态。预热只准备所选模型，不开麦，准备完成不自动开始录音。
- 识别文字插入当前光标附近的原始草稿，保留其他内容；完成后用户自行发送。手动编辑、切换、隐藏页面或断线按既有规则结束录音，已显示文字保留。
- 松开立即停止麦克风采集；识别收尾可以继续。模型正在处理与网络断开应按真实原因展示，不能用同一超时错误抹掉结果。
- 录音及收尾期间不切引擎；失败不自动换另一个模型。保留独立语音连接、PCM 背压、模型复用和相应闲置释放。
- 音频在内存中处理，不保存录音。系统识别是否联网由系统能力决定；CPU／GPU 模型运行与安装条件见 [语音指南](../voice-input.md)。
- Qwen 保留流式传输与增量预览；松手后复用同一个模型，对包含最后不足一块尾音的完整录音独立识别，以最终结果替换本次预览片段，不固定预览文字前缀。最终识别失败仍保留已显示的预览，不自动切引擎或发送。Sherpa 保持既有连续流及末尾补齐；本次没有增加 CPU 离线模型或第二次整段识别。

## 终端

1. 对话页和电脑栏终端入口共用 RA 终端列表；资源归属电脑和真实 RA 终端 ID，初始目录独立于 Agent、窗口及会话。仅需电脑连接认证，创建／选择／输入不要求 IDE 已打开或 attach 完成。
2. 新建入口复用终端列表和空状态；对话入口使用发起操作的真实项目为 cwd，电脑入口默认用户主目录。输入框不再提供选择目录新建按钮，创建后用 Shell 的 `cd` 改目录。终端使用 RA 用户的 Bash 交互配置，不继承另一终端手动激活的环境；目录更新来自同一 Shell 的提示信息。原生 IDE 终端不迁移、不关闭，原生终端上下文不自动映射到 RA 终端。
3. 使用输入框＋发送，输出区只读显示。普通文本、中文输入法、换行、Tab、连续候选及上下历史作用于同一个真实 PTY；当前 Ubuntu 的补全和历史复用该 Bash 的 Readline。命令草稿按电脑与终端 ID 保存，切换、迟到回读和后台恢复不能覆盖其他输入目标；聊天与 Question 草稿保持独立。
4. 密码使用独立掩码控件发送，不进入普通输入草稿、补全回读、日志或重放队列，回执不含输入正文；输入已提交不等于命令执行成功。普通命令由同一 Bash 执行，Shell 自身的历史及回显遵循其配置。
5. PTY 输出按事件推送，服务端保留屏幕及 1000 行回滚。初始逻辑尺寸为 120 列 × 50 行，支持调整；转屏和弹出键盘不自动缩小逻辑尺寸。程序换行保留，长行按列数折行，内容超出手机可视区域时双向滚动。复制有选区时复制选区，否则复制当前保留的输出，滚动／选择时不抢回光标。
6. 后台、断网、刷新、Session 保留到期和关闭 Agent 只释放订阅，不结束 Shell。重新认证后按终端身份恢复快照，再接连续增量；旧目标的输出不串到新目标，不自动重发输入。正常退出的 Shell 保留结束画面，主动关闭或 RA 服务退出结束该 PTY；不提供跨服务重启恢复。原生终端／后台进程的窗口管理约定仍见 [03](03-projects-sessions-windows.md)。

终端输入框上排仅保留终端列表、中断 Ctrl+C 和专用「更多」，下排是 Tab、上下历史、换行及发送；聊天页全局「…」菜单不承载这些操作。密码输入、复制、全选、尺寸和刷新输出复用现有弹层与终端操作，刷新恢复同一个终端身份，常用按钮在窄屏和横竖屏无需横向寻找。

## 绘图与仿真画面

画面入口只读查看 Matplotlib、Isaac Sim、MuJoCo 等目标窗口，支持选择、缩放、移动和刷新；不发送鼠标／键盘到目标，也不改为展示整个桌面或 Agent 编辑器。

Windows 按实际窗口句柄捕获，需要相应 FFmpeg；X11 使用窗口枚举与捕获，目标需保持可用；Wayland 通过系统窗口共享授权，恢复失败或撤销时重新授权。平台差异和具体依赖见 [使用指南](../usage.md)。退出最后一个查看者时结束相应捕获资源，保留既有授权语义。macOS 不在当前已列出的画面捕获实现中。

## 回归场景

| 操作 | 观察结果 |
|---|---|
| 从项目、聊天引用及变更列表打开同名不同目录文件 | 路径与内容正确，失败不静默替换目标 |
| 搜索／定位、换行、高亮、差异来源切换 | 显示与文件内容对应，标记不串文件 |
| 编辑、保存、未保存退出、保存时断线 | 回执准确，草稿保留，测试文件权限不改变 |
| 多页 PDF 前后翻页，视频播放和拖动，快速切文件／关闭 | 页码与内容正确，旧绘制停止，媒体控制正常 |
| 多图裁剪／标注／撤销／切图／排除及取消上传 | 编辑结果、逐图状态及已提交结果准确，失败后可继续操作 |
| 改图后取消编辑上传原图、编辑已有附件后取消 | 原图内容及尺寸保留；已有附件不替换，已提交图片不重复上传 |
| 附图／文档／电脑文件引用，上传中切目标或断线 | 附件不串会话，待发送状态与实际结果对应 |
| 跨目录下载、ZIP、子目录／空目录／符号链接 | 选择和归档范围符合约定，目标身份正确 |
| 多文件／文件夹上传，三种重名策略、取消、失败重试 | 路径、顺序、进度、临时清理及完成结果正确 |
| 新建、跨目录复制／剪切／粘贴、ZIP 压缩／解压 | 电脑与完整路径正确，逐项结果准确；大文件处理中控制连接仍可响应 |
| CPU／Qwen／系统识别的准备、录音、松开与切换 | 已安装能力、光标插入、开麦和收尾语义正确，不自动发送 |
| 语音中编辑草稿、断网、切会话或隐藏页面 | 停止对应资源，保留已显示文字，不写新会话 |
| 三 Agent 终端选择、输入、交互、控制键和复制 | 指定终端收到输入，输出／历史正确，不误发聊天 |
| 输入框发送、Tab／连续候选、光标中间编辑、历史与切终端 | 复用同一真实 Shell，回读不覆盖后续编辑；输入不误发聊天或其他终端 |
| A 项目会话位于 B 编辑器时新建终端 | RA 终端实际 pwd 为 A，不操作 B 的 IDE 终端或切项目 |
| watch 全屏输出、尺寸、后台／刷新恢复 | 下方数据按逻辑屏幕生成，可滚动；PID 保持，快照与增量连续，无输入重放 |
| 查看画面、换窗口、缩放、刷新、撤销授权和退出 | 只读、来源正确、资源结束；按实际平台分别记录 |

## 关联检查与维护

附件／语音读 [01](01-conversation-input.md)，显示及滚动读 [02](02-chat-display-history.md)，项目范围与占用读 [03](03-projects-sessions-windows.md)，原生变更读 [04](04-native-controls.md)，电脑／认证读 [08](08-connection-pairing.md)，权限／原生壳读 [09](09-client-delivery.md)。

本次建档未运行模型、执行终端命令、修改真实文件或上传／下载真实工作数据。回归使用独立测试文件与项目；不为检查附带安装或更新驱动。

收尾较慢的 CPU／Qwen 转录应继续接收真实最终结果；等待提示不是失败。等待时再按麦克风可以取消本次转录，已识别文字保留；重新录音仍由明确用户手势触发。文件未发出、读取中断和超时应结束加载，过期结果不能覆盖新文件。

图片与文档上传复用独立的已认证二进制 HTTP 请求；控制连接只提交图片上传记录，再使用原来的原生图片附加流程。图片处理尺寸与质量参数保持既有值，图片取消、替换、失败重试及目标归属与传输方式无关；附加完成或取消清理该图片临时文件。

图片编辑保存以本地结果加入附件上传流程为完成点，不等待 HTTP 上传。图片任务按入队顺序后台执行，真实原生附加完成仍由回执确认；待完成或失败待处理的图片保留进度／重试／取消，并继续阻止发送，替换成功前保留原图。
