# 06 文件、终端与媒体工具

[功能基准索引](README.md) · 首次建档：2026-10-26 · 核对起点：`24e4cd7` / `v250`

## 功能与范围

本类覆盖用户直接使用的电脑工具：Editor、文件预览和差异、图片／文档附件、图片编辑、双向文件传输、语音输入、终端及绘图／仿真画面。以下各功能独立保持自己的输入目标、权限和资源；同属一类不表示要合并实现。

## Editor 与文件预览

- 从项目文件、聊天引用或变更列表进入对应电脑和项目的文件。完整路径、相对路径和裸文件名要区分，同名不同目录不能静默替代。
- 展示实际文件名、路径和内容；文本保留原内容，按可用主题／语言高亮，可换行、搜索、定位和查看差异。
- Editor 在项目范围浏览与编辑。保存有明确回执，失败／未知保留编辑内容；未保存离开有确认。切文件时旧读取或旧绘制不覆盖新文件。
- 保存正文不得擅自改变原文件权限；可执行文件仍可执行，原有限制权限保持。
- Git 差异、Agent 差异和最近提交标记保持真实来源及文件身份；没有可定位行时不捏造对应关系。
- 图片展示及缩放使用真实引用；PDF 通过页码／上一页／下一页阅读全部可读页面，支持页面内双指缩放、放大后拖动和适应页面；翻页重置缩放，切换或关闭结束过期任务。
- MP4 保留播放、拖动及分段 Range 读取；双指缩放与移动不抢占原生播放控制条。

## 图片、文档与引用

1. 手机选择图片或文档，上传到当前电脑并归属于当前会话；展示进度、完成、失败和取消。
2. 图片可批量编辑，提供裁剪、比例、旋转、画笔／形状／文字、移动、撤销／重做、缩放及逐图排除。保存前是本地编辑，取消不替换电脑原件。
3. 批量保存按实际已加入上传的结果推进；取消后续上传不假装撤销已经提交的图片，单张失败不永久锁住整个编辑器。
4. 发送后按对应用户消息展示图片缩略图；历史图片是否能读取受原文件／缓存存在性约束，不能放错消息。
5. “添加电脑端文件”与“手机上传文档”是不同入口；@ 引用遵守 Agent 原生索引及路径语义。
6. 切电脑、会话或断线时，旧上传结果不加入新目标；待发送附件与消息接收关系见 [01](01-conversation-input.md)。

## 双向文件传输

| 功能 | 行为约定 |
|---|---|
| 浏览 | 当前电脑操作系统用户可访问目录，不限于项目；与 Editor 的项目范围分别处理 |
| 选择 | 跨目录多选、全选本页、清空；列表过滤不应悄悄改变已经选中的目标 |
| 下载 | 单文件直接下载，多文件／文件夹流式 ZIP；保留子目录与空目录，不跟随文件夹内部符号链接 |
| 上传 | 先选接收目录，再统一添加文件／文件夹并上传；按相对路径创建子目录 |
| 重名 | 用户选择另存、跳过或覆盖；不能把一项的选择应用到另一完整目标路径 |
| 并发 | 当前最多两个上传并行，同一完整目标路径按顺序处理 |
| 进度／失败／取消 | 各项状态对应真实结果，失败可重试；取消清理属于本次任务的临时资源，不撤销已完成结果 |
| 目录偏好 | 上传接收目录和下载浏览目录分别记忆；隐藏文件开关只控制列表展示 |
| 平台能力 | 浏览器未提供的目录／空目录信息不虚构；保存位置和下载取消由可用浏览器能力管理 |

## 语音输入

- 支持已安装的 Sherpa CPU、Qwen GPU 及可用的手机系统识别；选择按电脑记录在当前浏览器，不伪装引擎安装状态。
- 按住说话、松开收尾；首次授权、模型准备和真正录音是不同状态。预热只准备所选模型，不开麦，准备完成不自动开始录音。
- 识别文字插入当前光标附近的原始草稿，保留其他内容；完成后用户自行发送。手动编辑、切换、隐藏页面或断线按既有规则结束录音，已显示文字保留。
- 松开立即停止麦克风采集；识别收尾可以继续。模型正在处理与网络断开应按真实原因展示，不能用同一超时错误抹掉结果。
- 录音及收尾期间不切引擎；失败不自动换另一个模型。保留独立语音连接、PCM 背压、模型复用和相应闲置释放。
- 音频在内存中处理，不保存录音。系统识别是否联网由系统能力决定；CPU／GPU 模型运行与安装条件见 [语音指南](../voice-input.md)。

## 终端

1. 选择终端模式，读取当前原生终端及可用终端列表；终端与聊天分别保存输入历史和草稿。
2. 按原生能力选择／创建／关闭终端，明确目标。查看输出保持换行、连续行、ANSI 颜色及光标语义。
3. 输入框显示发送到终端；普通命令、交互输入、Ctrl+C、Tab 等进入所选原生终端，不作为 Agent 聊天消息。
4. 输入已提交不等于命令执行成功。交互程序及密码回显按原生终端自身规则处理。
5. 复制有选区时复制选区，无选区时复制当前已加载输出；调用命令历史不误替换其他终端输入。
6. 切换或关闭面板不擅自结束电脑进程。自动窗口回收对终端／后台进程的约定见 [03](03-projects-sessions-windows.md)。

## 绘图与仿真画面

画面入口只读查看 Matplotlib、Isaac Sim、MuJoCo 等目标窗口，支持选择、缩放、移动和刷新；不发送鼠标／键盘到目标，也不改为展示整个桌面或 Agent 编辑器。

Windows 按实际窗口句柄捕获，需要相应 FFmpeg；X11 使用窗口枚举与捕获，目标需保持可用；Wayland 通过系统窗口共享授权，恢复失败或撤销时重新授权。平台差异和具体依赖见 [使用指南](../usage.md)。退出最后一个查看者时结束相应捕获资源，保留既有授权语义。macOS 不在当前已列出的画面捕获实现中。

| 操作 | 观察结果 |
|---|---|
| 从项目、聊天引用及变更列表打开同名不同目录文件 | 路径与内容正确，失败不静默替换目标 |
| 搜索／定位、换行、高亮、差异来源切换 | 显示与文件内容对应，标记不串文件 |
| 编辑、保存、未保存退出、保存时断线 | 回执准确，草稿保留，测试文件权限不改变 |
| 多页 PDF 前后翻页，视频播放和拖动，快速切文件／关闭 | 页码与内容正确，旧绘制停止，媒体控制正常 |
| 多图裁剪／标注／撤销／切图／排除及取消上传 | 编辑结果、逐图状态及已提交结果准确，失败后可继续操作 |
| 附图／文档／电脑文件引用，上传中切目标或断线 | 附件不串会话，待发送状态与实际结果对应 |
| 跨目录下载、ZIP、子目录／空目录／符号链接 | 选择和归档范围符合约定，目标身份正确 |
| 多文件／文件夹上传，三种重名策略、取消、失败重试 | 路径、顺序、进度、临时清理及完成结果正确 |
| CPU／Qwen／系统识别的准备、录音、松开与切换 | 已安装能力、光标插入、开麦和收尾语义正确，不自动发送 |
| 语音中编辑草稿、断网、切会话或隐藏页面 | 停止对应资源，保留已显示文字，不写新会话 |
| 三 Agent 终端选择、输入、交互、控制键和复制 | 指定终端收到输入，输出／历史正确，不误发聊天 |
| 查看画面、换窗口、缩放、刷新、撤销授权和退出 | 只读、来源正确、资源结束；按实际平台分别记录 |

本次建档未运行模型、执行终端命令、修改真实文件或上传／下载真实工作数据。回归使用独立测试文件与项目；不为检查附带安装或更新驱动。

收尾较慢的 CPU／Qwen 转录应继续接收真实最终结果；等待提示不是失败。等待时再按麦克风可以取消本次转录，已识别文字保留；重新录音仍由明确用户手势触发。文件未发出、读取中断和超时应结束加载，过期结果不能覆盖新文件。

图片与文档上传复用独立的已认证二进制 HTTP 请求；控制连接只提交图片上传记录，再使用原来的原生图片附加流程。图片处理尺寸与质量参数保持既有值，图片取消、替换、失败重试及目标归属与传输方式无关；附加完成或取消清理该图片临时文件。

图片编辑保存以本地结果加入附件上传流程为完成点，不等待 HTTP 上传。图片任务按入队顺序后台执行，真实原生附加完成仍由回执确认；待完成或失败待处理的图片保留进度／重试／取消，并继续阻止发送，替换成功前保留原图。
