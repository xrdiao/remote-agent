# 功能使用指南

[返回 README](../README.md) · [English](usage.en.md)

## 主页、概览与收藏

主页提供「概览」「项目」「收藏」三个栏目，并记住上次选择；「…」中可设置默认进入概览或会话内容。

- **概览**按电脑列出会话及其运行、待处理、已完成和空闲等状态；空闲、不常用分组可展开。点电脑栏折叠项目或会话，点会话卡片展开最新摘要，展开后自动定位到卡片。摘要可上下滚动；可操作的 Cursor、Devin、Codex 会话可直接回复文字，完整历史、附件和其他操作通过「打开对话」进入。历史会话回复可能需要电脑端切换到目标会话；Fusion 保留自己的操作入口。
- **项目**按电脑浏览项目，再查看项目中的会话；收藏会话会列入常用，近 7 天有消息的会话也视为常用；其余归入不常用。
- **收藏**汇总所有电脑的收藏会话，包括项目窗口已关闭的记录；不会为展示收藏主动打开项目，只有点「打开对话」才加载对应项目或会话。
- 长按会话卡片可打开会话设置，进行收藏／取消收藏、重命名及原生支持的删除／归档。「…」中的批量管理支持多选、批量收藏和删除／归档，操作按条执行，失败会保留结果说明；各 Agent 的删除／归档能力以实际菜单为准。

电脑在主页中加载，完成后自动展开。持续不可达的电脑连续三次连接失败后暂停自动重试及数据读取，保留「重新连接」；恢复手机网络或回到前台时可再试连一次。这个状态不等于已经确认电脑关机。短时返回仍需恢复隧道并验证设备，服务端保留期内可复用已加载会话，过期后重新初始化。

PWA 会缓存核心页面资源；KaTeX 脚本、样式及字体不属于安装时的预缓存清单，首次离线打开时不保证完整公式展示。

## 对话、项目与会话

顶部切换 Cursor、Devin、Codex 或 Fusion；输入框中的「项目/会话」按项目分组列出会话，支持选择目录、创建项目和新建会话。切换到其他项目时保留已有窗口，不改变原会话的工作目录。Codex 优先复用该项目已打开的窗口，项目未打开时再开新窗口；新窗口可能需要电脑端登录或确认信任。

模型、思考强度和其他参数来自各 Agent 的原生菜单。额度显示剩余比例；上下文按原生提供的口径显示剩余或已用，具体取决于 Agent 与界面。只有提供原生价格的选项才显示价格，不估算单次任务费用。不同 Agent 的可用参数、排队和追加能力不同。

电脑列表的打开项目／会话入口先选择软件，再进入与对话页相同的列表。选择文件夹时，电脑入口从默认目录和最近项目开始，对话入口从当前项目开始；浏览和输入路径入口位于顶部，输入路径可按 Tab 或点「补全」。Fusion 选择项目使用同一目录浏览器，并保留已选电脑与软件。

横屏输入栏折叠后，工具按钮直接执行自身功能；点折叠栏空白区域展开，空闲自动折叠仍保留。

回车发送、Shift+回车换行，也可点发送栏的「↵」。屏幕 ↑↓ 保留输入历史；键盘使用 Alt/Option＋↑↓，单独 ↑↓ 留给光标和输入法。生成中可按 Agent 原生能力排队或追加，队列中的内容可编辑。

## 提问、审批与执行记录

Codex Question 可在卡片中选择预设或输入自定义答案；底部只保留跳过和发送两个操作，多题时按原生「下一题／发送」顺序推进。在卡片输入框按回车等同于点击该卡片的发送按钮，输入法选字回车不提交。Question 与主输入框分别保存草稿，不自动复制文字。聚焦 Question 输入框会临时折叠主输入区，也可用输入区右上角按钮切换折叠／展开。终端执行审批仍走它自己的同意、拒绝操作。

「… → 显示执行指令」按 Agent 记住选择；关闭时，本轮完成后隐藏执行和工具读取/搜索记录，思考、工作说明、结果、失败及待审批内容保留。不是删除历史。

## 附件与项目文件

手机可附加图片和文档；图片可在上传前编辑、裁剪、标注，已发送图片以缩略图显示在文字下方，点击查看原图。历史图片是否可恢复取决于本地记录或原始图片是否仍可读取。

Codex 的 `@` 使用原生索引搜索文件；「＋ → 添加电脑端文件」可浏览电脑目录并批量添加文件引用，与上传手机文件是不同入口。引用列表可独立滚动，收起键盘后仍保留。电脑列表和对话页的 Editor 使用同一个文件浏览器：前者从根目录／盘符开始，后者从当前项目开始；两处均支持输入路径、Tab／补全按钮、进入文件夹、预览和编辑保存。关闭预览返回原目录和滚动位置。文件预览支持代码高亮，改动提示可查看文件列表和具体差异。MP4 在预览面板播放，支持分段读取。

## 终端

从对话页顶部或主页电脑栏进入「RA 终端」。终端由中继在配对电脑启动，不依赖 IDE 面板；列表按电脑共享，显示已读取的目录和尺寸。在「终端列表」中选择「新建终端」；对话入口新建使用当前会话的真实项目，电脑入口默认用户主目录，创建后可用 `cd` 切换目录。切换会话或 Agent 不会改变已有终端的目录和进程。

输入框上排提供紧凑的「终端列表」「密码输入」「复制」「全选」；竖屏「更多」中保留尺寸和刷新输出，横屏直接展示这两项。下排提供「中断」（Ctrl+C）、Tab、上下历史、换行和发送。窄屏工具会自然换行；刷新输出恢复同一个终端，不重发命令。终端状态位于输入框左上沿，右上沿的文件图标仍打开当前关联对话的改动列表。

终端使用输入框＋发送，输出区只负责显示、滚动和选择，不再点击输出区调出键盘。输入框支持中文、换行、Tab 补全和上下历史；当前 Ubuntu 的补全与历史来自同一 Bash 的 Readline，重复 Tab 保留原生候选行为。普通命令提交到该 PTY；前台程序运行时，文本作为程序输入。密码使用独立掩码控件，经原始输入通路发送，立即清空，不进入普通命令草稿、补全回读或重放。返回聊天恢复原草稿。

初始尺寸为 120 列 × 50 行，竖屏从「更多 → 尺寸」调整，横屏直接点「尺寸」。程序自身的换行保留，长行按终端列数折行；手机旋转或弹出键盘只改变可视区域，显示不下时上下或左右滚动。全屏程序仍受设定尺寸约束。复制有选区时复制选区，否则复制当前终端保留的输出。

切后台、断网及刷新不结束 Shell，重新认证后恢复同一终端的屏幕及后续输出；断线期间输入不自动重发。退出的 Shell 保留结束画面，主动关闭终端会结束该 PTY；中继退出或重启会结束 RA 终端，不提供跨服务重启恢复。原 IDE 终端继续独立运行，手机不再列出或控制它们，Agent 的原生终端上下文也不自动包含 RA 终端输出。

当前 Ubuntu 新终端使用运行中继的用户及 Bash 交互配置，不继承另一 IDE 终端手动激活的虚拟环境和临时变量。本轮直接创建电脑本地终端；SSH／容器项目不能按远程路径静默创建本机 Shell，可选择本地目录后自行运行 ssh。

## 文件传输

主页电脑行右侧的文件传输图标用于操作该台已连接电脑，即使当前聊天选择的是另一台电脑也不会切换聊天目标；连接认证完成后即可使用，无需等待项目和会话读取完毕。断线电脑的同一位置保留连接详情。也可在「…」菜单右上角进入当前电脑的文件传输，浏览操作系统用户有权限访问的目录，不局限于项目目录。

从会话打开后，点返回或使用浏览器右滑返回该会话；从主页打开则返回原栏目、卡片及滚动位置。选择上传接收目录时，面板内的返回只取消本次目录选择。

- **下载到手机**：可跨目录多选、全选本页或清空选择；单文件直接下载，多文件和文件夹打包为流式 ZIP，保留子目录与空目录，不跟随文件夹内部符号链接。保存位置、下载进度和取消由浏览器管理。
- **上传到电脑**：先选择电脑接收目录，再添加多个手机文件或文件夹，检查待传列表后统一上传。支持进度、取消、失败重试，以及同名另存、跳过或覆盖；子目录自动创建。文件夹选择能力取决于手机浏览器，浏览器未提供的空目录无法保留。
- 上传目标和下载浏览目录分别记忆，互不联动。「显示隐藏文件」默认关闭；只影响列表，不剔除已选文件夹 ZIP 内的隐藏内容。
- 路径左侧「↑ 上一级」和路径栏吸顶，文件列表独立滚动。最多两个文件并行上传，同一完整目标路径按顺序处理；速度仍受网络、磁盘和隧道服务限制。

## 绘图与仿真画面

`… → 画面` 用于查看电脑上的绘图、仿真窗口（如 Matplotlib、Isaac Sim、MuJoCo），不再显示 Agent 编辑器或整个桌面。点“选择窗口”后选择目标，支持缩放和刷新；窗口画面只读，不发送鼠标或键盘操作。

- Windows：需要支持 `gdigrab hwnd=` 的新版 `ffmpeg` 在 PATH 中，按窗口句柄捕获，避免同名窗口混淆。
- Linux X11：需要 `ffmpeg`、`xprop` 和系统 Python 3，窗口需保持打开、可见。
- Linux Wayland：点“请求共享窗口”，在电脑端系统选择框中选择并授权一个绘图或仿真窗口。需要系统 Python 的 PyGObject、GStreamer 及 PipeWire 插件；Ubuntu/Debian 可安装 `python3-gi gir1.2-gstreamer-1.0 gstreamer1.0-pipewire gstreamer1.0-plugins-good gstreamer1.0-plugins-base`。系统允许时，恢复凭据保存在 `~/.agent-remote/visual.json`，下次优先恢复；窗口关闭、权限撤销或恢复失败时需重新授权。Cloudflare 隧道重连不改变这份授权记录。


macOS 画面捕获不在上述已列出的实现路径中。画面截图和浏览器模拟检查不等同于所有平台的真机验证。

## Fusion 协作

从主页底部“Fusion”进入独立工作区，与“概览／项目／收藏”同级。沿用当前电脑范围；全部电脑时分组展示，新建前明确执行电脑。导航只读取状态，不自动创建原生会话或发送任务。

选择项目、主 Agent 软件、主模型与思考强度，以及省钱／均衡／性能档位（默认均衡），再进入主对话。需要读取原生模型时，明确点击“读取当前原生模型”。主 Agent 决定自己执行或分批派发子任务，选择实际可用的软件、模型与强度，返回后进行验收、补做或交付；没有固定子任务数和评审轮数。

需要方案确认的项目先展示范围和完成标准，确认后执行；原生问题与权限在“任务与证据”中按实际目标处理。运行中可继续向主 Agent 补充要求，切页、退出或手机断线不停止后台任务。返回时恢复 Fusion 页及原电脑范围。

“任务与证据”显示依赖、执行记录、成本理由、结果、差异和阻塞。成本资料保留原生单位、来源与读取时间，未知金额如实显示；档位不限制模型或替换主模型。停止尚未确认时显示“正在停止”，原生结果未知时先核对，不自动重发。手动切会话或原生草稿会阻塞执行，草稿保留。

RA Fusion 编排与 Devin 自带的 Fusion 模型模式不同。旧 A/B 历史在正式切换时一次性清理，不迁移；其他状态、原生会话、收藏及项目映射保留。各环境的实际验证结果见 [实施与验证进度](fusion-multi-agent-plan-20261101.md)。

## 通知、外观与手机入口

支持深色、浅色和跟随系统，界面可切换中英文。PWA 可添加到主屏幕；仓库另含 Android / iOS 壳。通知在「…」中开启，可用能力取决于浏览器、系统授权及相应推送服务配置；iOS 实时活动还需要包含该扩展的原生构建，不代表网页发布即可获得所有原生能力。
