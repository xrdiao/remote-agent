# 语音输入

[返回 README](../README.md) · [English](voice-input.en.md)

在运行中继的电脑上安装 Python 3.10 或以上，然后在本仓库目录执行：

```bash
npm run voice:setup
```

安装器会先询问同意，再创建 `~/.agent-remote/asr/` 独立环境，安装 CPU 版 sherpa-onnx 并下载约 615 MB 的 X-ASR 160ms 中英混说模型。Windows 使用 Python Launcher（`py -3`）；Linux 可能需要先安装 `python3-venv`。可用 `ASR_SETUP_PYTHON` 指定安装时的 Python 可执行文件。不需要 GPU，运行时无需连接第三方识别服务。

手机通过 HTTPS 打开应用，在「…」菜单右上角点语音输入图标，开启开关，并从子列表选择已安装的语音识别引擎；只装一个就只显示一个，选择按电脑保存在当前浏览器。空闲时输入框右侧显示麦克风，**按住说话，松开结束**；第一次需允许浏览器使用麦克风，授权后重新按住即可。录音期间持续显示文字，中英文可混说；松开后补齐末尾文字，确认或编辑后自行发送。Agent 正在生成时，未使用输入框则显示停止按钮；开启语音后，展开输入键盘或正在输入时切成麦克风，输入结束保留约 2 秒缓冲，录音和转录收尾期间保持麦克风。关闭语音仍保留原停止按钮。

可选安装 Qwen3-ASR-1.7B，使用[官方 vLLM 流式接口](https://github.com/QwenLM/Qwen3-ASR/blob/main/examples/example_qwen3_asr_vllm_streaming.py)，目前安装入口需要 Linux 和可用 NVIDIA GPU：

```bash
npm run voice:setup -- --engine qwen
```

安装前另行询问同意，创建独立虚拟环境并下载约 4 GB 模型，运行依赖另计，不替换 Sherpa，不安装或更新系统显卡驱动和 CUDA。可加 `--dir /磁盘/语音目录` 指定环境和模型存放位置，安装完成后自动登记路径；重新打开语音子列表即可看到。Qwen 每约 1 秒音频进行一次增量识别，首次出字仍取决于模型和硬件；不需要手动切换中英文。录音和收尾期间不能切换引擎，完成后再选；切换失败不会自动换成其他引擎。Qwen 默认在独立识别进程中使用单进程 vLLM，冷启动比 Sherpa 更久，同一引擎连续录音仍复用模型与连接。模型未就绪时按麦克风会显示准备提示，不开启麦克风，也不会在加载完成后自动录音；就绪后重新按住即可。启动失败会显示具体原因，完整启动错误记录在中继日志中。`QWEN_ASR_GPU_MEMORY` 可设置 vLLM 显存比例，默认 0.35；该比例不是 GPU 隔离或不影响其他任务的保证。无 GPU 的电脑继续用 Sherpa。

识别文字插入当前光标位置，保留其他草稿；手动编辑、切换会话/页面或断线会停止录音，已显示文字保留，不会自动发送。首次加载模型会稍有等待，开关开启时，只预热所选引擎。认证完成及刷新恢复后立即在后台调用预热流程；在引擎列表里连续选择时，退出后保留 300ms 合并等待，只启动最终选择。预热复用现有进程和连接，不申请麦克风，也不创建录音用的 AudioContext。连续录音复用连接和音频环境；松手立即关闭麦克风并挂起音频环境，页面隐藏或关闭语音开关时释放连接和音频环境。可用 `ASR_THREADS` 调整中继识别进程的 CPU 线程数，默认 2。音频走独立连接，仅在内存中处理，不保存录音。

普通局域网 HTTP 地址无法申请麦克风权限，请用 HTTPS 固定入口或公网隧道。微信等内置浏览器不能开麦时，改用 Safari/Chrome，或使用输入法键盘的语音输入。Android 壳需要包含新的麦克风授权代码的构建；网页发布不会更新已安装的 APK。浏览器麦克风授权方式不变，不承诺网页能永久保存权限。


Qwen 录音期间继续显示流式预览；松手后使用同一个模型重新识别完整录音（包括尾音），再替换本次预览文字，因此最终文字可能修正前文，收尾也会比只刷新尾音多一次识别。音频仍只在内存处理。Sherpa CPU 保持原有连续识别和末尾补齐，没有额外安装或切换离线模型。

## 引擎选择

| 引擎 | 运行位置 | 要求 |
|---|---|---|
| Sherpa / X-ASR | 配对电脑，CPU | 独立 Python 环境，无需 GPU |
| Qwen3-ASR-1.7B | 配对电脑，GPU | 当前安装入口要求 Linux / NVIDIA GPU，冷启动更久 |
| 手机系统识别 | 手机 / 浏览器 | 仅支持该接口的浏览器可选；服务和联网需求由系统或浏览器决定 |

手机系统识别不经过电脑上的语音模型，不保证离线工作。选择后仍使用按住说话、松开收尾和光标处插入草稿的交互。录音期间不要切换引擎。

## 初始化失败时

确认在 HTTPS 页面中已授权麦克风，且没有其他应用占用录音设备。模型未准备完成时先等待提示就绪，再重新按住；不要把后台预热完成理解为已打开麦克风。微信等内置浏览器异常时可尝试 Safari / Chrome。

安装了包含麦克风授权处理的新版 iOS 壳时，App 自身页面的站点授权由原生桥处理；系统级权限仍由 iOS 管理。浏览器和旧版壳的授权行为可能不同，网页发布不会升级已安装的原生 App。
