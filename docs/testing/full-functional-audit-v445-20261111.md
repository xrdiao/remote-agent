## 二、范围、环境与能力

### 检查边界

- 四个普通应用、共享工具、Fusion、连接／安全、通知、PWA 和现有原生壳全部纳入清单；没有环境的项目保留待验，不能从总表删除。
- 用户已决定不处理 OpenCode 自动压缩策略及本地模型记忆能力。只检查 RA 对原生压缩提示、合成消息、错误、后续新消息的显示和同步；不调保留预算、摘要提示或模型参数，不专门触发压缩。
- Devin 的原生生成错误不预判持续存在或已经消失：先核对当前条件，原生仍失败则保留错误、停止依赖该结果的测试，不反复换模／换代理尝试。
- 原生软件、模型服务、网络及 RA 分别归因。模型生成质量不等于 RA 功能正确；原生已接收不等于任务完成，HTTP 可达不等于 WebSocket 正常。
- 普通功能按真实入口测试。内部函数和受控帧只用于定位及边界，不绕过禁用控件制造“真实通过”。

### v445 重点复现场景

| 编号 | 操作序列 | 预期与必留证据 |
|---|---|---|
| R01 | 无卡片展开 → 折叠卡片打开 → 返回 → 重复 | 点击到新鲜首屏的时序、成功率及请求数；等待提示准确，不随次数增加永久卡住 |
| R02 | 展开 A 读取摘要 → 打开 B；A 读取未完成时快速取消／改选 B | B 是最后有效目标；A 迟到结果不能进入 A 或覆盖 B，不把 A／B 合并成同一请求 |
| R03 | 竖屏 A → 终端 → 返回主页 → 卡片打开 B；横屏对照 | 进入 B 正文，不进入 A 终端、不闪 A 正文；已有终端及两处草稿保留 |
| R04 | Fusion 具体工作台／任务详情 → 返回 → 普通会话；再反向操作 | 默认只读必要摘要，详情按需；普通导航不等待全部 Fusion 历史，工作台回包不重新弹出 |
| R05 | OpenCode 本地模型真实生成中 → 返回 → 打开其他应用和原会话 | 分清“加载会话／等待正文／连接恢复”；生成推送不堵导航或心跳，离开不发送 abort |
| R06 | Cursor 电脑输出新正文 → 卡片与正文同时观察 → 手动刷新／切走返回 | 以原生消息 ID 对照新增内容，不能只有展开卡片看得到；虚拟列表之外的原生文本／图片不丢 |
| R07 | OpenCode 长历史首开 → 连续较早页 → 主页摘要刷新 → 返回重开 → 再读较早页 | 20 条指原生消息数，并非固定显示行数；不清空共享缓存、不回退游标、不反复空翻页；记录首屏／分页字节和请求数 |
