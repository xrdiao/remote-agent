仅处理 Devin 视图识别、IDE 初始化、项目目录与会话切换，以及 Cursor 原生会话打开和旧窗口恢复。用户另行允许修改共用文件中的 Devin／Cursor 专用分支，并授权 Devin 会话打开期间取得、释放实际目标窗口的焦点租约；公共焦点方法、公共导航语义和 Codex 保持本轮开始前内容。不新增配对，不刷新原生 Agent 页面，不停止真实任务，不测试或修改 Fusion。

本轮开始前的 108 项源码、版本及文档快照在 `_shots/devin-ide-cursor-restore-fix-20261029/source-before`。此前本地修改及未跟踪源码 `server/operations.mjs` 均保留；本轮差异按该快照核对，不能把整个工作区相对 HEAD 的差异算作本轮改动。未提交或推送 master／debug。

## 根因与实现

### Devin 视图与初始化

新版既有独立 Agents 窗口，也允许在同一个项目窗口切换 Agents／IDE 布局。窗口静态配置在切换后保持不变，原判断因此会把 Agents 布局继续当作 IDE。现在先读取原生模式控件的实际 `mode`，调用该控件自己的 `onSelect` 切回 IDE；不通过菜单动画中的坐标选择来切换。

默认进入、恢复及项目打开都在 Devin 专用入口完成 IDE 准备。已有正确 IDE 复用；目标属于其他项目时按真实工作目录定位／打开对应 IDE。没有明确项目时保留清晰的项目选择错误，不借用别的项目。

新项目窗口出现不代表聊天面板和历史入口已经挂载。初始化通过原生 Agents 面板入口打开聊天，不对可能聚焦终端的窗口发送 Ctrl+L。面板入口和正文可读使用既有启动等待预算，历史选择器等待实际入口就绪；不以模式状态已变或窗口已出现提前结束。未添加失败后的自动重试链。

### Devin 目录和会话归属

主动列表、其他 IDE 窗口列表与共享窗口目录统一使用原生有效会话目录，保留未打开为标签的会话及其 workspace／运行状态／标题元数据。开放标签仅补充当前标签状态，不替代完整目录。项目窗口从实际 IDE 和真实目录产生，不从独立 Agents 的底层编辑器配置推断。

旧列表携带已关闭的来源窗口时，先按原生会话 ID 读取实际项目，避免依赖过时的目录缓存。同项目仍在当前窗口换会话，跨项目才匹配／打开窗口。

跨项目切换后，公共导航原有焦点租约仍属于旧窗口，新 IDE 的历史选择器会关闭。只在 Devin 的打开会话阶段，为实际新窗口取得既有焦点租约；已被持有的不重复取得，只释放本次取得的租约。没有修改公共焦点函数，也没有为焦点问题叠加延时或重试。

### Cursor 原生打开与旧恢复

原代码依赖已挂载的列表行，而原生目录中存在尚未出现在侧栏／正文的有效会话。现在由原生目录核对 ID、归档状态及服务就绪，再调用原生 `openComposer(id)`。正文就绪确认保持原规则。

项目重开仍沿用原有恢复流程和等待预算，只把就绪依据改为原生会话服务可用；不存在、归档、尚未初始化分别反馈，不把列表没挂载当作会话被删除。旧窗口失效后依旧按保存的真实项目恢复，失败沿既有初始页结束流程处理。
