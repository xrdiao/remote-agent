# Markdown 格式与图片上传耗时排查

日期：2026-10-27。用户现场：Codex 回复的文档链接显示为原始 Markdown，且图片上传变慢。本轮只排查，未修改产品代码。前一轮 Safari 刷新／缓存／恢复排查仍保留，见 `refresh-codex-audit-20261027.md`；新问题没有替代前一轮问题，也不表示已获准实施新增修复。

## Markdown：已确认两处根因

1. `server/page/chat-extract.js:400–403` 只有匹配到原生 Markdown DOM、且该块绑定内容与原文完全一致时才保留格式。未挂载或匹配失败则使用 `esc(item.content).replace(/\n/g, '<br>')`，这只是文本转义，不是 Markdown 渲染。
2. `server/apps/codex.mjs:304` 的合并会用后来的纯文本 HTML 覆盖同一正文以前读取到的富文本 HTML。按钮保留不等于正文格式保留。

隔离执行实际提取函数，传入标题、加粗、列表、文件链接和代码块：原文完整、Copy 仍存在，但对应 HTML 标签缺失，原始 Markdown 直接显示。再执行真实合并函数，确认相同正文已经保存的 strong／data-file 被后续未挂载快照覆盖。

截图中的具体回复没有在当前打开的原生会话历史中匹配到，因此上述是已证实的实现缺陷及复现条件，不能冒充已对该手机截图中的具体消息完成逐字核对。

### 建议修改

- 对未挂载的原生回复按原始 Markdown 正常渲染，保留标题、列表、表格、强调、代码、数学和文件链接；不通过滚动电脑端以强制挂载来获取格式。
- 相同正文的格式合并以实际正文和渲染来源为依据，不能把“未读到原生 DOM”当成“正文应该降级”。
- 继续使用既有 HTML 允许范围、代码块及文件引用语义；复制仍取原始正文。不得把正文与 Copy／Fork／Retry 的动作状态合并成一套缓存规则。

影响范围：Codex 回复提取、历史／实时内容的格式合并，以及必要的 Markdown 渲染依赖；不修改滚动、发送、按钮点击或其他 Agent 的会话行为。须回归未挂载、刷新、生成转完成、文件链接和代码块复制，并确认 Retry 仍按实时状态显示。

## 图片：分段测试结果

复用原已配对 Chrome，在自有 Codex 测试项目上传生成图片；没有发送聊天消息。每张测试后移除附件，最后核对前端没有 pending 图片、原生输入框没有测试附件，恢复原选择。以下不是 iPhone 真机性能结果。

| 项目 | 小图 | 大图第一次 | 大图分段复测 |
|---|---:|---:|---:|
| 原始 PNG | 166 B | 2,219,836 B | 2,219,836 B |
| 实际图片文件 | 166 B | 714,185 B | 714,185 B |

复测在图片之后立即发送独立、可绕过操作队列的原生延迟探测，回执在图片发出后 7,277 ms 到达，电脑已在约 7,153 ms 开始粘贴。因此这次没有证据表明图片在到达后还因操作队列多等了数秒；不能把整个 7–13 秒归为服务器排队或图片压缩。

### 已确认的软件开销

- `app/js/voice.js:148–154` 将图片转换成 Base64 放入 JSON，通过普通控制 WebSocket 上传。714,185 B 的 JPEG 对应约 952 KB 的消息缓冲，较二进制图片多约三分之一。
- 本次实测连接没有协商 WebSocket 压缩；这只是测试连接结果，不代表所有 Safari／隧道都有同样设置。
- 图片和控制请求共用一条 WebSocket。图片大消息传完之前，其后的控制消息也要等待；快速探测同样在大图传输之后到达，符合这一行为。
- 当前 v274 未改图片压缩、编码或图片粘贴实现。本轮没有取得相同图片／相同链路在旧版本的对照数据，不能声称已经证实“最近哪次改动使上传退化”。

### 建议修改

如果实施图片上传改造，保持现有尺寸和质量参数，复用现有已认证二进制上传设施传送图片，控制 WebSocket 只携带上传结果及当前选择身份，再调用原有原生图片附加流程。这样减少 Base64 传输膨胀，并避免大图片数据阻塞普通控制消息。

图片仍须作为模型原生图片附件，不能降级成文本路径或普通文档。保留编辑后上传、替换、取消、逐张结果、切换目标归属和发送前附件状态。不要增加另一套通用任务队列或通过降低清晰度掩盖等待。

影响范围：图片上传入口、认证上传接口、临时图片交接和原生附加回执。文档／文件传输继续保持各自功能；共享上传设施如有改动，需要回归其既有路径。外部链路吞吐带来的时间不计为软件本身可消除的延迟，不承诺改造后固定多少秒完成。
