# Remote Agent 宣传动画 · 分镜（v2）

总长约 54 s，1920×1080，虚拟时钟 + `scene()` 时长列表 + `?t=` 跳转。文案全部在 `ra-strings.js`（`<b>` 为强调色）。

## 核心叙事

Agent 在电脑上跑长任务，人得出门。手机远程桌面字小、点不准；Remote Agent 只把 Agent 接到手机，并用手机原生界面重新排版。之后电脑与手机同时可见、逐步一致：实时同步 → 提问通知一点即答 → 按住说话同步到电脑输入框 → 更多能力速览 → 完成通知 → 收尾。

一句话主张：**不用远程桌面，手机直接遥控 Agent。**（EN: *No remote desktop. Just your agent, on your phone.*）

## 视觉规则（全程浅色；只有 theme 镜头约 1 s 为深色）

- 整个演示（舞台、电脑桌面/IDE、手机 App）默认浅色。所有颜色走主题变量，舞台根节点与每个 iframe 的 `html[data-theme]` 同步切换，深色变量作为 theme 镜头使用。
- 浅色舞台：底色 `#F6F6F4`，两团缓慢漂移的柔光（紫 `rgba(91,80,232,.10)` 左上，蓝 `rgba(47,143,224,.08)` 右下），极淡点阵。深色舞台：底色 `#0A0B0E`，柔光 `rgba(143,135,255,.18)` / `rgba(80,160,255,.10)`。不要漂浮的描边方框。
- 色板取自 `app/app.css` 对应主题。浅色：强调 `#5B50E8` / 文字强调 `#4A3FD4`，成功 `#12844F`，等待 `#A15C00`，错误 `#CC2F2F`，正文 `#1D1E21`，次要 `#6C7078`。深色：`#8F87FF` / `#ABA5FF`，`#4ADE9B`，`#FBBF4D`，`#FF6B6B`，`#E8E9EB`，`#8A8E96`。
- 电脑端 IDE 为 Cursor 风格浅色主题（深色镜头里切到 Cursor 风格深色）。
- 字幕：底部居中，单行，40px（中文 42px）600，浅色为正文色、`<b>` 用 `#5B50E8→#2F8FE0` 渐变字（深色为 `#ABA5FF→#7FD3FF`），必须清晰高对比；无底框，仅柔和投影。不再有“✕ 痛点 → ✓ 解决”删除线小标题、时间牌、地点牌、小人。
- 品牌水印：品牌镜头之后，左上角常驻小图标 + “Remote Agent”。
- **手机画面 = 真实 App 界面**：`phone.html` 在 iframe 中加载 `../app/app.css`，按真实 DOM 结构/类名渲染模拟数据（浅色主题、竖屏手机布局）。状态栏（时间、信号、电量）和灵动岛属于手机外框。
- 不用镜头推拉（会裁掉手机顶部）；需要强调手机时，把显示器和中继压暗到约 45%，之后恢复。
- **单一数据源，两个渲染器**：会话状态对象 `AG` 的每次变化，同时渲染到电脑 Agent 面板（Cursor 风格深色面板，真实文字）和手机（postMessage 给 iframe）。除 A2 飞行克隆外，不允许单独改某一端。
- 手机端只用手指涟漪，电脑端无指针。

## 布局

- 全景：显示器外框 1320×780，屏幕是桌面：底部任务栏，IDE 后面露出两扇非 Agent 窗口（浏览器、文件夹）。IDE 为 Cursor 风格：标题“auth-service — Cursor”，三栏——文件树 | 编辑器（真实代码、语法色）+ 其下终端（`npm test` 输出，内容跟随 `AG` 的测试计数，不能提前出现结果）| Agent 面板约 420px，**紧贴 IDE 右边缘、占满标题栏以下到 IDE 底部的整列高度**，输入框完整可见（IDE 底边在任务栏之上）。
- 侧移：显示器 `translate(40,130) scale(.85)`，手机外框位于 `P=(1290,70)`，约 387×810（屏幕 393×852 CSS px 按 0.92 缩放）。
- 分屏：显示器 `translate(120,250) scale(.58)`；手机仍在 P；两者之间是中继连线（流动光点 + 标签 `relay`）。

## 删除的旧内容及原因

- 冷开场 C0、三张痛点卡 S0：合并成一个 4 s 的远程桌面对比镜头（rdp）。
- A7 模型菜单、A8 扫码配对：不够抢眼；配对与自托管放进收尾卡片。
- 小人、椅子、时间牌、地点牌、“不需要”标签、删除线小标题：画面噪音。
- “不经第三方服务器 / 数据不出你的设备”：公网模式经过 Cloudflare 隧道，这个说法不准确，不再使用。

## 两个关键实现点

1. **飞行与重排**：飞行的是电脑 Agent 面板当前状态的克隆；落地瞬间克隆淡出，iframe 里的手机渲染器（同一份状态、App 真实排版）淡入接管。
2. **同步保证**：除了飞行克隆，任何会话内容都只能通过 `AG` 的操作函数修改；手机端只接收状态快照与特效命令（点按、切屏、键盘、语音），不自己改会话内容。
