# Remote Agent 宣传动画 · 分镜

总长约 75 s，1920×1080，虚拟时钟 + `scene()` 时长列表 + `?t=` 跳转 + 字幕条（痛点→解决 kicker）。
所有实机画面都用几何构成：文字行 = 圆角灰条；只有关键文字（提示词、工具名、问题、通知、输入内容）用真实文字。

## 核心叙事

人离开电脑，Agent 不会停；问题是**人控制不了自己电脑上的 Agent**。现有办法是远程桌面，但手机上的远程桌面画面太小、要不停缩放、点不准，而且整个桌面（浏览器、文件夹、修图软件……）都塞了进来，用户其实只想控制 Agent。

> 长任务在跑 → 人起身出门、带上手机 → 桌面上只有 Agent 面板飞进手机（其他窗口留在电脑上），并按手机重新排版 → 之后电脑和手机同时可见、逐帧对得上 → 手机回答提问、手机打字同步到电脑、完成时手机提醒 → 收尾。

一句话主张：**不用远程桌面，手机直接遥控 Agent。**（EN: *No remote desktop. Just your agent, on your phone.*）

## 视觉规则（亮色调）

- 背景：浅色渐变 `#F6F9FD → #EAF1FA`，漂浮的淡蓝描边圆角框。主色 `#1E88E5`，成功 `#1A9F5A`，等待/提问 `#C98A12`（浅底 `#FFF4DC`），痛点 `#E5484D`，正文 `#1E2433`，次要文字 `#5B6B80`，文字灰条 `#DCE3EC`。
- 卡片、窗口、字幕条都是白底，配柔和阴影（`0 20px 60px rgba(30,60,110,.14)`）和 1px `#E2E8F0` 描边。
- IDE 用浅色主题：白色编辑器、浅灰侧栏、彩色代码条（蓝/紫/绿/橙的浅饱和色）。终端可以保留深色小面板，作为点缀。
- 手机：深色边框（真实手机的样子），屏幕内容为浅色。
- **单一数据源，两个渲染器**：Agent 会话是一个状态对象（消息列表、测试进度、草稿、提问、状态）。每次变化同时渲染到「电脑」和「手机」，两边永远一致。
- 电脑端没有鼠标指针（人不在）。手机端用手指点按涟漪，不用指针。
- 右上角时间牌：12:02 → 12:15 → 12:28 → 12:41。
- 地点牌：电脑下方「电脑 · 工位」，手机下方「手机 · 餐厅」。

## 布局

- **桌面全景（A1）**：显示器外框 `[200,70,1320,780]`，支架 + 桌面线 y≈870；右侧是坐着的人（侧面朝左），桌上放着手机。
  - 屏幕是一个真实桌面：底部任务栏。后面层叠着几个非 Agent 窗口：浏览器（地址栏 + 网页色块）、文件夹（图标网格）、修图软件（画布 + 工具栏）。
  - 最前面是 IDE：标题栏，左边文件树，中间编辑器，下方终端，右边 Agent 面板（440 px）。
- **分屏（A2 之后）**：显示器缩到约 0.52，移到左侧，中心约 (560,440)；手机 430×880，位于 (1250,60)。
  - 两者之间是虚线通道，上面有流动光点，标签「自托管中继 · 隧道」。

## 两个关键实现点

1. **A2 飞行与重排**：飞行的是 Agent 面板当前状态的克隆；落地瞬间克隆淡出，手机渲染器（同一份状态、手机排版）淡入接管，看起来就是“飞进来后重新排版”。
2. **同步保证**：除了 A2 的克隆，任何会话内容都只能通过状态对象的操作函数修改，不允许单独改某一端。
